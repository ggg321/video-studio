How it works
  1. Choose a project that has been analyzed. Below are the moments that have no fitting clip, each with a ready prompt.
  2. Copy a prompt, generate the clip in Flow (or any video generator), download it.
  3. Drop the file onto that moment. It is added to the niche library and placed on that moment right away.
Open Flow ↗You generate in your own Flow account. The platform never logs in or automates Flow.
